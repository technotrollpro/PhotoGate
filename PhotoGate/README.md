# PhotoGate

[![Arduino Library](https://img.shields.io/badge/Arduino-Library-blue.svg)](https://www.arduino.cc/reference/en/libraries/photogate/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/version-1.0.0-green.svg)](https://github.com/technotrollpro/PhotoGate/releases)

**Простая и надёжная библиотека для работы с датчиками типа «фотоворота» (photo gate) на Arduino Nano/Uno.**

---

## 📌 Что это и зачем?

PhotoGate позволяет обрабатывать прерывания от датчиков препятствия и превращать их в удобные события — с антидребезгом, счётчиком и поддержкой нескольких датчиков.

**Типичный кейс:**  
Вы спаяли оптическую пару (выпаяли светодиод и фотодиод из датчика препятствия, расположили их напротив друг друга) — луч прерывается, когда что-то проходит. Библиотека ловит этот момент через прерывание и сообщает программе.

**Но можно использовать любой датчик**, который выдаёт сигнал LOW при срабатывании (механический концевик, щелевой датчик, фототранзистор, лазерный барьер — неважно). Главное — подключить его на пины 2 или 3 (Arduino Nano/Uno), где аппаратно поддерживаются прерывания.

---

## 🎯 Возможности

- ✅ Поддержка **двух независимых датчиков** (пины 2 и 3)
- ✅ **Аппаратные прерывания** — ничего не пропускаем
- ✅ **Антидребезг** (настраивается, по умолчанию 5 мс)
- ✅ **Встроенный счётчик срабатываний** (с чтением со сбросом или без)
- ✅ **Мгновенный опрос состояния** — `isBlocked()`
- ✅ **Компактный код** — идеально для маленьких проектов

---

## 🔌 Подключение

| Пин Arduino | Куда подключать |
|-------------|----------------|
| 2 или 3     | Выход датчика (LOW при срабатывании) |
| GND         | GND датчика |
| 5V          | Питание датчика (если нужно) |

> В большинстве дешёвых датчиков препятствия (например, с компаратором LM393) выход уже сформирован — просто подайте питание и подключите SIG к пину 2 или 3.

## 🛠 Установка

### Через менеджер библиотек Arduino IDE (рекомендовано)

1. Скетч → Подключить библиотеку → Управлять библиотеками...
2. В поиске введите `PhotoGate`
3. Установите

### Вручную

1. Скачайте ZIP-архив с [GitHub](https://github.com/technotrollpro/PhotoGate)
2. Скетч → Подключить библиотеку → Добавить .ZIP библиотеку
3. Выберите архив

## 📖 API

### Конструктор и инициализация

| Метод | Описание |
|-------|----------|
| `PhotoGate(int sensorPin, int gateId = 0)` | Конструктор. `sensorPin` — пин датчика (только 2 или 3). `gateId` — произвольный идентификатор (по умолчанию 0). |
| `void begin()` | Инициализация. Обязательно вызвать в `setup()`. Подключает прерывания. |

### Работа с событиями

| Метод | Описание |
|-------|----------|
| `bool check()` | Возвращает `true`, если было срабатывание с момента последнего вызова `check()`. Автоматически увеличивает внутренний счётчик. |
| `bool isBlocked()` | Возвращает `true`, если датчик заблокирован прямо сейчас (сигнал LOW). |

### Счётчик срабатываний

| Метод | Описание |
|-------|----------|
| `int getCount()` | Возвращает количество срабатываний с момента последнего сброса и **обнуляет счётчик**. |
| `int peekCount()` | Возвращает текущее значение счётчика **без сброса**. |
| `void resetCount()` | Сбрасывает счётчик в 0. |

### Настройки и идентификатор

| Метод | Описание |
|-------|----------|
| `void setDebounceMicros(unsigned long micros)` | Устанавливает время антидребезга в микросекундах (по умолчанию 5000 = 5 мс). |
| `int getId()` | Возвращает ID датчика. |
| `void setId(int id)` | Устанавливает ID датчика. |

### Пример использования API

```cpp
#include <PhotoGate.h>

PhotoGate gate(2, 1);  // пин 2, ID = 1

void setup() {
  Serial.begin(9600);
  gate.begin();
  gate.setDebounceMicros(3000);  // антидребезг 3 мс
}

void loop() {
  // Проверяем событие
  if (gate.check()) {
    int events = gate.getCount();  // получим количество (счётчик обнулится)
    Serial.print("Срабатываний с прошлого раза: ");
    Serial.println(events);
    
    // Общий счётчик без сброса
    Serial.print("Всего срабатываний: ");
    Serial.println(gate.peekCount());
  }
  
  // Проверка состояния прямо сейчас
  if (gate.isBlocked()) {
    // Луч перекрыт
  }
  
  delay(10);
}

## ⚠️ Важные замечания

1. **Поддерживаемые платформы:** AVR (Arduino Uno, Nano, Mega, Leonardo).  
   Для ESP8266/ESP32/STM32 потребуется адаптация — прерывания там настраиваются иначе.

2. **Только пины 2 и 3** (для Arduino Nano/Uno).

3. **Прерывания короткие** — внутри обработчика только установка флага. Вся логика — в `check()`.

4. **Дребезг** — для механических контактов увеличьте `setDebounceMicros` до 10 000–50 000 мкс. Для оптических пар 5000 мкс достаточно.
